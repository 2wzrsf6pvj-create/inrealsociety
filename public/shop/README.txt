Mockups produit pour la boutique (galerie ProductGallery dans ShopClient.tsx).

Dépose ici les visuels générés par le Mockup Generator de Printful (gratuit) :

  tee-noir-dos.webp     ← t-shirt NOIR, vue DOS (avec le QR) — le plus important
  tee-noir-face.webp    ← t-shirt NOIR, vue FACE
  tee-blanc-dos.webp    ← t-shirt BLANC, vue DOS (avec le QR)
  tee-blanc-face.webp   ← t-shirt BLANC, vue FACE

Format : .webp de préférence (ou .png — alors renomme le chemin dans ProductGallery).
Carré idéalement (aspect 1:1), ~1000x1000 px. La galerie les affiche automatiquement
dès qu'ils sont présents ; sinon elle retombe sur le placeholder abstrait (aucun bug).
